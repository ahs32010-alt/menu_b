# نظام إدارة قائمة المطعم

نظام إدارة محتوى (CMS) كامل لإدارة قائمة المطعم مع قاعدة بيانات SQLite.

## المميزات

- ✅ إدارة كاملة للمنتجات (إضافة، تعديل، حذف)
- ✅ إدارة الأقسام
- ✅ رفع الصور للمنتجات والشعار
- ✅ قاعدة بيانات SQLite لحفظ جميع البيانات
- ✅ واجهة أدمن سهلة الاستخدام
- ✅ عرض ديناميكي للقائمة من قاعدة البيانات

## التثبيت

1. تأكد من تثبيت Node.js على جهازك

2. قم بتثبيت المكتبات المطلوبة:
```bash
npm install
```

## التشغيل

قم بتشغيل الخادم:
```bash
npm start
```

أو للتطوير مع إعادة التشغيل التلقائي:
```bash
npm run dev
```

## الوصول

- **الصفحة الرئيسية**: http://localhost:3000
- **لوحة التحكم (الأدمن)**: http://localhost:3000/admin

## الاستخدام

### إدارة المنتجات

1. اذهب إلى لوحة التحكم: http://localhost:3000/admin
2. اضغط على تبويب "المنتجات"
3. اضغط "إضافة منتج جديد"
4. املأ المعلومات:
   - القسم
   - اسم المنتج
   - الوصف
   - السعر
   - الصورة (اختياري)
   - ترتيب العرض
5. اضغط "حفظ"

### إدارة الأقسام

1. في لوحة التحكم، اضغط على تبويب "الأقسام"
2. يمكنك إضافة أقسام جديدة أو تعديل/حذف الأقسام الموجودة

### رفع الشعار

1. في لوحة التحكم، اضغط على تبويب "الإعدادات"
2. اختر صورة الشعار وارفعها
3. سيتم حفظ الشعار تلقائياً

## قاعدة البيانات

يتم حفظ جميع البيانات في ملف `menu.db` (SQLite) والذي يتم إنشاؤه تلقائياً عند أول تشغيل.

### الجداول:
- `categories`: الأقسام
- `products`: المنتجات
- `settings`: الإعدادات العامة

## الملفات

- `server.js` - الخادم الرئيسي
- `database.js` - إدارة قاعدة البيانات
- `public/index.html` - الصفحة الرئيسية
- `public/admin.html` - لوحة التحكم
- `public/app.js` - JavaScript للصفحة الرئيسية
- `public/admin.js` - JavaScript للوحة التحكم
- `public/style.css` - التنسيقات العامة
- `public/admin.css` - تنسيقات لوحة التحكم

## ملاحظات

- الصور يتم حفظها في مجلد `images/`
- الحد الأقصى لحجم الصورة: 5MB
- الصيغ المدعومة: JPG, PNG, GIF, WebP

## الدعم

في حالة وجود أي مشاكل، تأكد من:
1. تثبيت جميع المكتبات (`npm install`)
2. أن المنفذ 3000 غير مستخدم
3. وجود صلاحيات الكتابة في المجلد
